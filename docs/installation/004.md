Install [Claude CLI](https://code.claude.com/docs/en/setup#npm).
* Via NPM `npm install -g @anthropic-ai/claude-code`.

Install plugins. These commands are run **inside Claude Code** (the `/plugin` slash command). First register the marketplaces the plugins come from, then install each plugin as `plugin@marketplace`. Run `/reload-plugins` (or restart Claude Code) to apply.

1. Add the marketplaces. `claude-plugins-official` and `claude-code-plugins` ship with Claude Code; add the custom ones:
    * `/plugin marketplace add makenotion/claude-code-notion-plugin`
    * `/plugin marketplace add blader/humanizer`

2. Install the plugins:
    * `/plugin install playwright@claude-plugins-official`
    * `/plugin install code-simplifier@claude-plugins-official`
    * `/plugin install frontend-design@claude-plugins-official`
    * `/plugin install ruby-lsp@claude-plugins-official`
    * `/plugin install humanizer@humanizer` — https://github.com/blader/humanizer
    * `/plugin install notion-workspace-plugin@notion-plugin-marketplace` — install from within the project you want it in (local scope), not globally.

> The same operations are available from a shell via the CLI, e.g. `claude plugin marketplace add blader/humanizer` and `claude plugin install humanizer@humanizer`. Verify with `claude plugin list`.
