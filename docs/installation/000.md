### Prepare Apple Workstation : 000

1. Boot into safe mode and reformat the hard drive using the naming convention `RBRHD`. 

> Please note, it may require APFS to successfully complete the next step, that is ok, we will confirm FileVault is enabled during this workflow. 

2. Reinstall the latest version of the OSX operating system. 

3. Under `Customize Settings` I `Enable Location Services` and do not share `Mac Analytics`, `Crash Data`, `Ask Siri`, and I uncheck `Store files from Documents and Desktop in iCloud Drive`. 

4. If prompted, make sure to turn on `FileVault disk encryption` and `Allow my iCloud account to unlock my disk`. 

> Please note since the OSX Tahoe release FileVault is enabled by default and no longer requires the user to turn it on. This step may be verification only. 

6. Under `System Settings` navigate to `FileVault` and confirm it is enabled. If it's not, turn it on, and wait for days! 

5. Under `System Settings` navigate to `Pointer` settings to adjust the cursor.
    * Size to be `max - 3`.
    * The outline color to be `red`.
    * The fill color to be `white`.

6. Under `System Settings` navigate to `Software Update` and make sure `Automatically Check for Updates` is checked, and `Download new available updates in the background` and `Install system data files and security updates` are both checked. 

7. Under the `App Store` install `Xcode`.

8. Open `Xcode` to approve the EULA, and install the iOS components because we want the iOS emulator. Do not install the predictive code completion model at this time. 

9. Open `Terminal` and run `xcode-select --install` to install the xcode developer tools.

10. Open `Safari` to download and install [1Password](https://1password.com/downloads/mac).

11. After installing the application, install `1Password` into [Safari](https://1password.com/downloads/browser-extension).

12. Under `System Settings` under `Users & Groups` verify or disable the `Guest User` from being able to access the computer, then reboot the machine to confirm.

13. In `System Settings` under the `Trackpad` adjust the settings.
    * In `Scroll & Zoom` Disable `Natural` scrolling if applicable.
    * In `Trackpad` under `Point and Click` set the tracking speed to `5`. 

14. Under `System Settings` under `Captions` set to `Large Text`.

15. Under `System Settings` under `Spotlight` uncheck to help Apple improve search.

16. Under the `Menu Bar` only show `Weather`, and `Wifi` should be checked.

17. In `System Settings` under `Displays` set `Resolution` to `scaled` and select `more space`. Set resolution to 4K when applicable.

> Please note, these settings are usually only applicable for a laptop configuration, when not fully integrated into the monitor configuration.

18. Under `System Settings` under `Hot Corner Shortcuts` configure `Hot Corners`.
    * Top-Left: Application Windows
    * Bottom-Left: Desktop
    * Top-Right: Mission Control
    * Bottom-Right: Lock Screen

9. Under `System Settings` configure `Set up Spaces` to uncheck `Automatically rearrange spaces based on most recent use` if applicable.

20. Under `System Settings` configure `Keyboard Shortcuts`.
    * Under `Mission Control` set `Mission Control` to `F3`
    * Under `Mission Control` set `Show Notification Center` to `F4` or `SHIFT+CMD+N` for the Logitech Keyboard Configuration.
    * Under `Mission Control` uncheck all other settings in this panel.
    * Under `Display` set `Decrease Display Brightness` to `F1`
    * Under `Display` set `Increase Display Brightness` to `F2`
    * Under `Spotlight` remove all shortcut settings, especially to show spotlight search and show finder search window.

21. Remove every application icon from the dock except Finder on the bottom left, and the trash can on the bottom right!

22. In `System Settings` configure the `Dock & Menu Bar`.
    * Enable `Magnification` and set it to `max`.
    * Enable `Automatically hide and show the Dock`.
    * Adjust the size of the menu to `4`.

23. Setup at least `4 OSX Spaces` via `Mission Control`.

24. In `System Settings` in `Keyboard & Mouse Shortcuts` in `Mission Control` desktop switches to use `ctrl + #` for the first 4 spaces.
> If the list doesn't show all your Spaces, quit System Settings completely (Command + Q), reopen it, and check again—sometimes it needs a refresh after adding new Spaces.

25. In `Finder Settings` under the `General` Section set.
    * Only check `Hard Discs` and `External Discs`.
    * Set `New Finder windows show:` to the user's home directory.
    * `Open Folders in tabs instead of new windows` should be checked.
    * `Sync Desktop & Documents folders` should be unchecked.
    * In `Keep folders on top:` make sure to check `In windows when sorting by name`.
    * Check `Show all filename extensions`.

26. In `Finder Settings` under the `Sidebar` Section set.
    * Only check the following: Airdrop, Applications, Desktop, Documents, Downloads, iCloud Drive, Shared, Hard Discs, External Discs, Trash, and Cloud Storage
    
27. In `Finder Settings` under the `View` settings in the nav bar set.
    * Set `as list` for the default viewing.
    * Set `Sort By` as `Name`
    * Set `View Toolbar`
    * Set `View Path Bar`
    * Set `View Status Bar`
    * Set `Show Tab Bar`
    * Select `Always open in list view`

28. Right click on the desktop and access advanced show options.
    * 
    * Sort by  `Snap to Grid`

29. Create a symlink named `WIP` on the Desktop pointing to the iCloud Drive WIP folder via: `ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/WIP ~/Desktop/WIP`

30. Send screenshots to the Desktop's `WIP` folder via: `defaults write com.apple.screencapture location "$HOME/Library/Mobile Documents/com~apple~CloudDocs/WIP"` followed by `killall SystemUIServer`.

31. In the `Terminal` application run `defaults write com.apple.iCal "n days of week" 14` to set the macOS calendar to display 14 days in week view.

32. In the `Calendar` application, under `Advanced` check the box to `Turn on time zone support`.
